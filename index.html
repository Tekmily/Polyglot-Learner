export const highlightWord = (sentence, word, color) => {
  const regex = new RegExp(`(${word})`, 'gi');

}

2. Yazı Boyutu ve Tipografi Kontrolü

Dinamik Font Ölçekleme Algoritması Kelime uzunluğu, ekran genişliği ve kullanıcı ayarlarını harmanlayarak kartın bozulmasını engelleyen matematiksel hesaplama. const getDynamicFontSize = () => {
  const maxFontSize = isMobile ? settings.maxFontSizeMobile : settings.maxFontSizeDesktop;
  let calculatedSize = maxFontSize;
  if (wordLength > 5) calculatedSize = maxFontSize * (8 / wordLength);
  return Math.max(settings.minFontSize, Math.min(maxFontSize, calculatedSize));
}
Kullanıcı Tanımlı Limitler Ayarlar sayfasından kontrol edilebilen 3 ana parametre:
  • Minimum Font Size: 4px - 24px (Varsayılan: 4px)
  • Max Font Size (Mobile): 24px - 64px (Varsayılan: 48px)
  • Max Font Size (PC): 48px - 120px (Varsayılan: 72px)

3. Zor Kelime (Difficult Words) Yönetimi

Arama ve Manuel Ekleme Tüm kelime havuzu (Sistem + Kullanıcı) içinde anlık arama yaparak kelimeleri "Zor" listesine ekleme/çıkarma yeteneği.
Özel Çalışma Oturumu (Difficult Session) Sadece zor olarak işaretlenen kelimelerden oluşan, ana akıştan bağımsız öğrenme döngüsü.
Hızlı Erişim Kartları Ana sayfada en çok zorlanılan 3 kelimenin anlık gösterimi ve yönetim paneline hızlı geçiş butonu.

7. Kullanıcı Deneyimi (UX) Prensipleri

Mobile-First & Responsive Navigation Alt menü (Bottom Navigation), 6 ana öğeyi (Ana Sayfa, Öğren, Zor Kelimeler, Test, Öğrenilenler, Ayarlar) mobil ekranlarda kaydırma gerektirmeden sığdıracak şekilde optimize edilmiştir. `flex-1` ve `min-w-0` kullanımıyla butonlar ekran genişliğine göre dinamik dağılır.
Görsel Geri Bildirim (Haptic Feedback) Aktif menü öğesi `scale-110` efekti ve canlı renk vurgusuyla belirtilir. Kart çevirme ve sürükleme işlemlerinde akıcı Framer Motion animasyonları kullanılır.
Erişilebilirlik ve Okunabilirlik Kelime uzunluğuna göre otomatik font ölçekleme ve 4px minimum font sınırı ile her cihazda okunabilirlik garantilenir.
